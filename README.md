# Pizza & Birra

A browser game to learn the best pizza and beer pairings: pick your ingredients, then match the pizza to the right beer style.

**Play it here: https://eatsjobs.github.io/pizza-birra/**

Static HTML5 game built with the Cocos2d-JS 3.x framework, served directly via GitHub Pages from the `main` branch.

I developed this product while doing an internship at [Balzo s.r.l.](https://www.balzo.eu) in 2014-2015, using the Cocos2d-JS 3.x game framework.
